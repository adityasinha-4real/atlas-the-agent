## Demo script (for the GIF)

1. `docker compose up -d ollama && docker compose exec ollama ollama pull qwen2.5:7b-instruct`
2. Add `ATLAS_AGENT_ENABLE_REFLECTION: "true"` to the backend's `environment:`
   in `docker-compose.yml` (do not commit it), then run `docker compose up --build`.
3. At http://localhost:3000, enter a multi-step goal, e.g. *"Compare the
   populations of France and Germany and compute the ratio."*
4. Record the plan checklist ticking, tool calls in the feed, a reflector
   critique/retry if one occurs, and the synthesized answer. Save it as
   `docs/assets/demo.gif` and swap it into the README placeholder.

A retry depends on what the model outputs, so it may take a few goals to
capture one on camera.
