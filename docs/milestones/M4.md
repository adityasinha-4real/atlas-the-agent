# Milestone M4 — Self-correction agent

**Status:** ✅ complete (v0.4.0)

**Demo:** with reflection enabled, a goal whose first attempt is weak is **retried**
with a critique; a goal whose plan is wrong is **replanned** from the current state;
a goal that cannot be finished **gracefully aborts** with a clearly-marked partial
answer. The checklist shows attempts, reflection verdicts, replans, and skips live;
per-run budgets bound the whole thing. Persisted and replayable exactly like M1–M3.

> Reflection is **opt-in**: `ATLAS_AGENT_ENABLE_REFLECTION` defaults to **off**, in
> which case behavior is byte-for-byte M3 (invariant I-13). The `echo` provider path
> is unchanged; the reflect/retry/replan/abort/budget flows are exercised
> deterministically by the FakeLLM (`ScriptedGateway`) tests.

Full design rationale: [RFC-0002](../rfc/0002-m4-self-correction.md) and its
[architecture validation](../rfc/0002-m4-architecture-validation.md).

## 1. Objectives

1. **Reflector** — a stateless component that grades a task attempt and returns a
   validated `accept | retry | replan | abort` verdict (deterministic pre-check +
   LLM verdict + acceptance bias, [ADR-0011](../adr/0011-reflector-acceptance-bias.md)).
2. **Retry loop** — a rejected attempt re-runs with a critique of its prior output
   folded into context (≤ `agent_max_retries`, default 2); **every attempt is
   preserved** in `task_attempts`.
3. **Replanning** — a `replan` verdict (or retry-exhaustion) re-plans the *remaining*
   work into a new generation at monotonic indices; dropped tasks are `SKIPPED`,
   completed tasks immutable (≤ `agent_max_replans`, default 1,
   [ADR-0013](../adr/0013-replan-from-current-state.md)).
4. **Graceful abort** — an `abort`/exhaustion synthesizes a partial answer over
   completed outputs and finalizes `FAILED`-with-answer
   ([ADR-0014](../adr/0014-graceful-abort-partial-answer.md)).
5. **Budgets** — a per-run `RunBudget` hard-caps model and tool calls, enforced by
   `BudgetedGateway`/`BudgetedToolRegistry` wrappers; `BudgetExceeded` → `FAILED`,
   no partial ([ADR-0012](../adr/0012-central-budget-enforcement.md)).
6. **Cancellation** works at every point of the retry/reflection/replan loop; no task
   is ever left non-terminal on a terminal run (invariant I-4).
7. **Persistence + migration** — `task_attempts` table + new `tasks` columns via an
   idempotent light migration ([ADR-0015](../adr/0015-light-sqlite-migrations.md)).
8. **API + frontend exposure** — attempt/generation on events and views; new events
   and statuses rendered on the checklist and feed.

## 2. The control loop

```
for each task (per plan generation):
  attempt = 1
  loop:
    run executor → output ; record attempt
    if reflection disabled: decision = accept
    else: decision = Reflector.reflect(goal, task, output, attempt)   # + task.reflected
    match decision:
      accept → mark done ; task.completed ; next task
      retry  → if retries_left: critique → attempt++ ; task.retrying ; loop
               else: escalate
      replan → if replans_left: escalate (replan)
               else: escalate
      abort  → escalate (graceful abort)
escalate ladder: retry/replan (if a replan remains) → else graceful abort
budget hit anywhere → budget.exceeded ; FAILED (no partial)
cancel anywhere     → task.cancelled ; remaining task.skipped ; CANCELLED
```

Precedence: **cancellation > budget > abort/replan**. Reflection disabled forces
`accept`, so the loop degenerates to M3's single attempt per task.

## 3. Event sequence (enabled)

- **Retry:** `task.started{a:1}` → `task.reflected{retry}` → `task.retrying{a:2}` →
  `task.reflected{accept}` → `task.completed{a:2}`.
- **Replan:** `task.reflected{replan}` → `task.skipped×`(dropped) →
  `plan.replanned{generation, dropped_task_ids, tasks}` → `task.started`(new gen).
- **Graceful abort:** `task.reflected{abort}` → `task.failed` → `task.skipped×` →
  `answer.completed{partial}` → `run.failed` (`RunView.partial = true`).
- **Budget:** `budget.exceeded{budget, limit, used, task_id?}` → `task.failed` →
  `task.skipped×` → `run.failed` (no `answer.completed`).
- **Cancel:** `task.cancelled{phase}` → `task.skipped×` → `run.cancelled`.

Executor `thought`/`tool.call`/`tool.result` events additionally carry `attempt` and
`generation`. All events keep a monotonic per-run `seq`; replay is purely
event-derived (invariant I-1).

## 6. Acceptance tests

Reflection loop, budgets, and contracts are covered deterministically by the FakeLLM:

- `test_reflector.py` — pre-check, malformed/invalid/degraded verdicts, confidence
  repair, acceptance bias.
- `test_budget.py` — hard caps, category counters, retry/replan accounting, wrappers.
- `test_runtime_m4.py` — retry→accept, retry-exhaustion→replan, replan swap +
  generations, abort→partial (completed-work-only), model/tool budget exhaustion,
  cancellation at every checkpoint + cancellation-vs-budget precedence, executor
  attempt/generation tagging, reflection-disabled parity.
- `test_persistence.py` — `task_attempts` CRUD/ordering, cascade delete, migration
  idempotency on a v0.3.0-shaped DB.
- `test_api_runs.py` — `TaskView` attempt/generation fields, `RunView.partial`.
- M1/M2/M3 tests remain green (**188 tests total**).
