# Milestone M1 — Walking Skeleton

**Status: complete (v0.1.0).**

## 1. Objective
Prove the entire stack and the model seam on day one: a user types a goal in a
web page, the backend streams an answer from the LLM, and the browser renders it —
with every step persisted as a replayable event. This thin chat exists only to
stand up the full pipeline; the agentic layers replace its runtime in M2+ while
reusing all of its machinery (runs, events, `emit()`, WS, gateway).

## 2. Scope (files created)
Backend (`backend/atlas/`):
- `core/config.py`, `core/logging.py` — env config + logging.
- `agent/schemas.py`, `events/types.py` — **frozen** contracts.
- `persistence/models.py`, `database.py`, `repositories.py` — WAL SQLite + repos.
- `llm/gateway.py`, `llm/providers/{ollama,echo}.py` — provider seam.
- `events/hub.py`, `events/emit.py` — WS fan-out + `emit()` seam.
- `runtime/manager.py` — `RunManager` thin flow.
- `api/{app,deps,routes,ws}.py`, `main.py` — FastAPI wiring.

Frontend (`frontend/`): `app/`, `components/RunPage.tsx` (+ `EventFeed`,
`StatusBadge`), `lib/{api,types,useRunStream}.ts`.

Infra/docs: `docker-compose.yml`, Dockerfiles, `Makefile`, READMEs,
`ARCHITECTURE.md`, `TODO.md`, ADRs.

## 3. Acceptance criteria
1. `GET /health` returns `{status: "ok", llm_provider: ...}`. ✅
2. `POST /runs {goal}` creates a run and returns it with an id. ✅
3. The run reaches `done`; `answer` is populated. ✅ (echo: contains the goal)
4. `GET /runs/{id}/events` returns an ordered ledger starting at `seq=1` and
   containing `run.created`, `answer.token`+, `answer.completed`, `run.completed`. ✅
5. `GET /runs/{id}/events?after=N` returns only `seq > N`. ✅
6. `WS /runs/{id}/stream` streams events to a terminal event; reconnues via
   backfill; replays a finished run from `after=0`. ✅
7. Unknown run → REST 404 / WS close 4404. ✅
8. Frontend builds, typechecks, serves the Run page; a submitted goal streams
   tokens into the answer panel and event feed. ✅
9. `make test-m1` (pytest, echo provider) is green — 24 tests. ✅

## 4. Verify
```bash
# Backend gate
cd backend && .venv/Scripts/python.exe -m pytest        # 24 passed

# Real-server smoke (echo)
ATLAS_LLM_PROVIDER=echo .venv/Scripts/python.exe -m uvicorn atlas.main:app &
curl -s localhost:8000/health
RID=$(curl -s -XPOST localhost:8000/runs -H 'Content-Type: application/json' \
      -d '{"goal":"hello"}' | jq -r .id)
curl -s localhost:8000/runs/$RID/events        # ordered ledger

# Frontend
cd frontend && npm run typecheck && npm run build && npm run start
```

## 5. Out of scope (deferred)
Tools, planner, reflector, memory, tasks table, History page — see later
milestone specs. M1 intentionally ships a *thin* runtime.

## 6. Assumptions made
- pip + `requirements.txt` (no poetry/uv present).
- Python 3.14 locally → wheel-only installs; Docker uses 3.12.
- `echo` provider stands in for Ollama (not installed) for the demo and all tests.
- `ATLAS_` env prefix; SQLite DB under `ATLAS_DATA_DIR`.
